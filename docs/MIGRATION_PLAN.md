# Historical Data Migration & Reconciliation Plan

## 1. Objectives

Migrate all historical source files (`Input folder`) and legacy Excel workbooks (`Output folder`) into the canonical SQLite database (`database/app.db`) while:
1. Archiving every untouched original file into `data/raw/` with SHA-256 verification.
2. Preventing duplicate counting when both raw source files (`2026.xlsx`, `2026_YEAR.xlsx`, `2026F.xlsx`, `ATRL.txt`..`TRG.txt`, `TradeLog-16-10-2026_ALL.txt`) and derived legacy workbooks (`PSX_Top5_Volume_Rate...xlsx`, `Trade_Summary_Account_91404...xlsx`, `Trade_Summary_Account_91269...xlsx`, `Futures_Analysis (3).xlsx`, `PSX_RSI_Pivot_Analysis (4).xlsx`) contain overlapping dates.
3. Reconciling every derived calculation generated by our new Python engine against the legacy Excel workbooks and recording all findings in `docs/MIGRATION_REPORT.md`.

---

## 2. Step-by-Step Migration Execution Order

### Step 1: Pre-Migration Safety Backup & Schema Initialization
- Initialize SQLite database with WAL journal mode and foreign-key enforcement.
- Archive all 33 Google Drive files into `data/raw/drive_initial/` and register them in `source_files`.

### Step 2: Module A Migration (Top 5 Volume & Rate Register)
1. **Historical Workbook Baseline (`PSX_Top5_Volume_Rate_12-08-2026_to_16-10-2026 (1).xlsx`)**:
   - Parse all 23 ticker worksheets (`ATRL`..`TRG`), extracting all `961` date blocks (`4,805` ranked rows covering `2026-08-12` to `2026-10-16`).
   - Load dates `2026-08-12` through `2026-10-15` (`938` blocks, `4,690` rows) as historical baseline records (`origin = 'LEGACY_WORKBOOK'`).
2. **Raw TXT Ingestion & Reconciliation (`Input folder/ATRL.txt` .. `TRG.txt` for `2026-10-16`)**:
   - Parse all 23 raw `.txt` files for `2026-10-16` (`23` blocks, `115` Top 5 rows) using our deterministic Module A parser (`origin = 'RAW_TXT'`).
   - Compare the 115 raw-calculated Top 5 rows for `2026-10-16` against the 115 rows in the `10/16/2026` blocks of `PSX_Top5_Volume_Rate_12-08-2026_to_16-10-2026 (1).xlsx`.
   - Store the `2026-10-16` rows once in `top5_volume_records` (total `4,805` unique rows across `961` ticker-dates).
